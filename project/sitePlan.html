VibeBoard Site Plan

Lucas Machado

WDD 131

1. Site Name

VibeBoard

Reason: The name combines "vibe" (representing aesthetics, mood, and inspiration) with "board" (referencing a blank canvas or pinboard). It immediately communicates to the user that this is a space to collect and organize visual ideas.

2. Site Purpose

VibeBoard is a dynamic visual discovery platform designed to help creators, designers, and developers find and organize inspiration. The site provides a curated gallery of high-quality images in a responsive masonry layout. Its primary service is allowing users to browse, filter by category, and discover visual references to overcome creative blocks and fuel their own projects.

3. Scenarios

  • "I am starting a new web design project and need inspiration for a minimalist layout. Can I easily find and filter UI/UX design references here?"
  • "I'm building a mood board for a brand identity. How can I quickly browse trending color palettes and save the best visual examples?"
  • "I only have my smartphone with me while commuting. Can I comfortably scroll through the inspiration gallery without the layout breaking?"

4. Color Scheme

The site utilizes an "Aurora UI" glassmorphism theme. The following colors are used throughout the website and on this very document.

Cyan Glow #06B6D4
Dark Base #0F172A
Glass Panel rgba(255,255,255,0.05)
